# Registro restrito de aprovação assinada — candidata de 20/10/2026

Esta candidata adiciona somente a tela /app/pilot-pix/approval/, mantendo a prévia existente. Ela recebe o arquivo JSON já assinado pelo operador, verifica seu escopo/encoding e solicita três callbacks Google recentes (auditoria, comprador, auditoria) com nonces próprios de instalação. A assinatura Ed25519 é verificada no backend privado com a chave pública fixada; a página não declara assinatura criptograficamente válida apenas pela leitura do arquivo.

O destino é fixo no relay pilot-approval, que encaminha ao privado pvapproval com IAM. O backend separado exige todas as onze flags de emissão/entrega false, valida as duas contas, relê vínculo/plano canônico e registra apenas a aprovação idempotente. Esta tela não assina, não emite Pix e não concede Premium.
